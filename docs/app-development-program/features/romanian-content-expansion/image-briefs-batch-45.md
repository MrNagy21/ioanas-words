## Common Pixel-Art Requirements

Each image brief below uses the `docs/image-pipeline.md` Batch 45 requirements:

- high-clarity, child-friendly, refined pixel-art game icon;
- polished, lightly dimensional pixel-art volume, not flat vector art, emoji art, photorealism, or smooth CGI;
- apparent source density near a refined `96 x 96` to `128 x 128` pixel icon upscaled cleanly;
- one centered concrete subject only, except minimal object context where required for recognition;
- full square cell background or transparency, with no gutters, side bars, rectangular panels, corner blocks, or cut-background artifacts inside the cell;
- circle-safe composition, with meaningful subject pixels inside the inscribed circle of the square;
- clean silhouette, limited internal detail, clear small-thumbnail readability, and consistent scale, outline weight, pixel density, palette softness, and contact-shadow style;
- no text, letters, numbers, logos, brands, watermarks, copyrighted characters, clutter, scary mood, violence, weapons, adult themes, or confusing extra objects;
- child-safe for ages `4` to `6`.
