# Vorbini release, 2026-10-26

## Scope

The user authorized deployment and closing this thread. This release includes the child-first workspace, automatic wheel-target goals, focused profile settings, history-aware navigation, Vorbini branding, Romanian legal drafts and the mobile adult footer. It preserves browser-only child records and the existing public Vercel project.

Starting a targeted round creates or reactivates that child's goal. Each closed word counts as participation for the chosen wheel target. Reviewed phonetic statistics remain separate. The reward schedule is 1, 3, 5, 10, then every 10; migration preserves the next promised medal. Adult pronunciation observations do not automatically change rewards.
