# Romanian Content Program

This document defines content priorities for Romanian expansion.

## Content Principles

Words must be:

- common;
- concrete;
- child-known for roughly ages 4 to 6;
- easy to illustrate;
- culturally appropriate;
- useful for vocabulary or pronunciation practice.

Avoid:

- obscure words;
- abstract words;
- frightening or violent words;
- adult, political, legal, financial, or specialized terms;
- slang;
- brands;
- copyrighted characters;
- visually ambiguous concepts.

## Speech Therapy Research Summary

Romanian logopedie sources consistently identify later or harder sounds around:

- `R`;
- sifflants `S`, `Z`;
- hushing sounds `Ș`, `J`;
- affricates and related groups such as `Ț`, `CE/CI`, `GE/GI`;
- practical parent-facing guidance also flags `F` and `V`.

Useful sources:

- Clic Psihologic on dislalie: https://clicpsihologic.ro/dislalia/
- iTeach on preschool language disorders: https://iteach.ro/experientedidactice/importanta-corectarii-tulburarilor-de-limbaj-la-varsta-prescolara
- Logoped.info.ro on dislalie: https://www.logoped.info.ro/post/dislalia
- Cabinet Logopedic ANDU on rotacism: https://cabinetlogopedic.ro/rotacismul/
- Dictie.ro on difficult sounds `S`, `Ș`, `J`, `Z`, `CE-CI`, `GE-GI`: https://www.dictie.ro/cum-corectam-sunetele-dificile-la-copii-s-s-j-z-ce-ci-ge-gi/

Research should guide prioritization, not override child vocabulary quality.

## Priority Tiers

### Tier 1: Highest Practice Value

Target more examples, usually up to 40 approved starts-with words where quality allows, plus strong contains pools.

- `R`
- `S`
- `Ș`
- `Z`
- `J`
- `Ț`
- `CE/CI`
- `GE/GI`

### Tier 2: High Practice Value

Target 30 to 40 approved words where quality allows.

- `F`
- `V`
- `L`
- `C`
- `G`

### Tier 3: Common Core Vocabulary

Target 25 to 40 approved words depending on available child-friendly vocabulary.

- `A`
- `Ă`
- `B`
- `D`
- `E`
- `I`
- `Î`
- `M`
- `N`
- `O`
- `P`
- `T`
- `U`

### Tier 4: Quality-Limited Or Rare

Use fewer words if needed. Do not pad.

- `Â`
- `H`
- `K`
- `Q`
- `W`
- `X`
- `Y`

## Starting Words Versus Contains Words

Do not create separate duplicated contains-word manifests.

Expansion workflow:

1. Add canonical starting-letter words.
2. Generate coverage report in `/admin/words`.
3. Identify weak contains pools.
4. Add more canonical words under their true starting letters to improve those contains pools.

Example:

- To improve `Ș`, add or approve words like `mașină`, `ușă`, `pește`, `coș`, `roșie` under their true starting-letter files.

## Romanian Letter Groups

Romanian references identify letter groups such as:

- `ce`
- `ci`
- `ge`
- `gi`
- `che`
- `chi`
- `ghe`
- `ghi`

Useful sources:

- LimbaRomana.net on the Romanian alphabet and letter groups: https://limbaromana.net/fonetica/fonologia/ortografia-si-ortoepia/alfabetul-limbii-romane/
- Romanian class manual excerpt covering the groups: https://www.librariaonline.ro/rasfoieste-editie-digitala/comunicare-in-limba-romana-manual-pentru-clasa-a-ii-a-ordin-de-ministru-nr-5268-04-08-2023-grigore-adina-ars-libri-attachment-1.pdf

These should be future practice targets, not normal letters.

## Image Rule

Every approved production word should eventually have one canonical image.

Reuse the canonical image wherever the word appears:

- starts-with mode;
- contains-only mode;
- mixed mode;
- future practice-target modes.

## Candidate Review Checklist

For every new word:

- Is it common for Romanian children aged 4 to 6?
- Is it concrete and imageable?
- Is it safe and culturally appropriate?
- Does it fit the target category list?
- Is the spelling and diacritic use correct?
- Is it in the right canonical starting-letter file?
- Does it improve a priority letter or weak contains pool?
- Can one clear image represent it?

## Source Metadata

Current content supports `source: ["manual"]`. If future batches use external lexical or curriculum references, extend allowed source values deliberately and document them before adding those records.
